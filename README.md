# 🌙 Bedtime Stories — Hindi Kahani Website

Personalized **Hindi bedtime stories for kids**. Parents choose a theme and the
child's age, generate a story with the child's name, and read or **listen** with
natural AI Hindi narration.

**🌐 Live site:** https://karma1911.github.io/bedtime-stories/

## ✨ Features

- 📖 **18 original Hindi stories** across 6 themes (animals, moral, adventure & more)
- 🪄 **Personalized story generator** — child's name, age & theme
- 🎙️ **AI Hindi narration** — 4 natural Hindi AI voices with pause/resume/stop
- ⏲️ **Bedtime timer** — 5 / 10 / 15 minute sleep timer
- 🌌 **Calm reading mode** — distraction-free night reading
- 🔤 **Font size control** & reading progress bar
- 👨‍👩‍👧 **Parent login** (demo) & curated story library
- 💾 Copy / download stories

## 🚀 Run locally

Just open `index.html` in any modern browser — no build step needed.
(The AI voices load from Hugging Face on first use; needs internet.)

## 🛠️ Tech

Single self-contained HTML file. AI narration via Hugging Face
(Kokoro Hindi TTS) running in-browser; device Hindi voice as fallback.
